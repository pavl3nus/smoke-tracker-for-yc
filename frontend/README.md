# SmokeTracker 🚭

Дневник курильщика - приложение для отслеживания и анализа привычки курения.

## 📋 О проекте

SmokeTracker помогает пользователям отслеживать их привычку курения, предоставляя инструменты для:
- Ведения дневника курения
- Анализа статистики и паттернов
- Постановки целей по снижению потребления
- Визуализации прогресса

## 🛠 Технологии

### Frontend
- **React 18** + TypeScript
- **Vite** - сборка и разработка
- **TanStack Query** - управление состоянием и кэширование
- **React Router DOM** - маршрутизация
- **Mantine UI** - компоненты и стилизация, формы и валидация
- **Recharts** - визуализация данных

### Backend & Tools
- **JSON Server** - моковый REST API
- **Axios** - HTTP-клиент
